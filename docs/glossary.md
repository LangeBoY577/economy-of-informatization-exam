# Глоссарий

| Термин | Определение |
|---|---|
| ARPU | Средний доход на пользователя за период |
| CAC | Стоимость привлечения одного клиента |
| CAPEX / OPEX | Капитальные (разовые) и операционные (текущие) затраты |
| Churn | Доля клиентов, уходящих за период |
| COCOMO II | Параметрическая модель оценки трудоёмкости разработки ПО по размеру и поправочным факторам |
| CPM | Стоимость 1 000 рекламных показов |
| EVPI / EVSI | Ожидаемая ценность совершенной / выборочной (неполной) информации |
| IRR | Внутренняя норма доходности, ставка, при которой NPV = 0 |
| LTV | Пожизненная ценность клиента: ARPU (или маржа) / churn |
| NPV | Чистая приведённая стоимость: Σ CF_t / (1 + r)^t |
| Payback (PP, DPP) | Простой и дисконтированный срок окупаемости |
| ROI | Возврат на инвестиции: (выгоды − затраты) / затраты |
| TCO | Совокупная стоимость владения за жизненный цикл |
| НМЦК | Начальная (максимальная) цена контракта в госзакупках |
| Закон Мэткалфа | Ценность сети пропорциональна квадрату числа пользователей: V = kN² |
| Критическая масса | Минимальное число пользователей, при котором сеть становится самоподдерживающейся |
| Проклятие победителя | Систематическая переплата победителя аукциона с общей ценностью |
| Реальный опцион | Право (но не обязанность) принять инвестиционное решение в будущем |
| Транзакционные издержки | Затраты на поиск, заключение, контроль и защиту контрактов |
| VRIO | Критерии ресурса как источника конкурентного преимущества: ценность, редкость, неимитируемость, организация |
| Функциональная точка (ФТ, FP) | Единица измерения функционального размера ПО |
