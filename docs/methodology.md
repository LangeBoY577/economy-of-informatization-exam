# Методологические пояснения

## Общий подход

Каждое решение построено по требованиям курса: постановка задачи, исходные данные, математическая модель, расчёт на Python,
визуализация, интерпретация, выводы. Общие правила:

- **Когда учитываются деньги:** разовые затраты в момент t = 0 (не дисконтируются), текущие потоки в конце периода t,
  дисконтирование $1/(1+r)^t$.
- **Главный критерий NPV**, а IRR, ROI и сроки окупаемости дополнительные (лекция №8).
- **Анализ чувствительности** есть в каждой задаче, где неопределённость большая, добавлен метод Монте-Карло.
- Если условие неполное или противоречивое, допущение прямо записано в ноутбуке, а другая трактовка показана в расчёте.
