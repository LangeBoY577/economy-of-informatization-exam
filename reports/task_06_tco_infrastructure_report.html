1. Экономическая постановка задачи¶

Компания «ТехноГос» выбирает инфраструктуру для госпортала на 5 лет: свой ЦОД (on-premise), облако (IaaS + PaaS) или гибрид. У вариантов разная структура затрат. Свой ЦОД: много денег сразу (CAPEX) и мало потом (OPEX). Облако: почти только ежегодные платежи, которые растут. Гибрид посередине. Сравнивать по цене покупки нельзя, нужна совокупная стоимость владения (TCO) с учётом времени.

Цель: выбрать вариант с минимальной приведённой TCO и проверить, не поменяется ли выбор при других условиях.

Тема лекции №7: структура TCO (прямые и косвенные затраты), CAPEX и OPEX, дисконтирование, точка безубыточности.

3. Математическая модель¶

$$TCO_{PV} = \sum_{t=0}^{5}\frac{C_t}{(1+r)^t},\qquad C_t = CAPEX_t + OPEX_t + Налог_t$$ $$Налог_t = 0{,}022\cdot\Big(K - \tfrac{K}{5}(t-0{,}5)\Big),\qquad Облако_t = 16\cdot1{,}05^{\,t-1}$$ Точка безубыточности это срок $T^*$, на котором накопленные приведённые затраты двух вариантов сравниваются: $\sum_{t\le T^*}PV(C^{on-prem}_t) = \sum_{t\le T^*}PV(C^{облако}_t)$.

def avg_residual_tax(capex, t):
    """Налог на имущество за год t: 2.2% от среднегодовой остаточной стоимости."""
    if t < 1 or t > dep_years:
        return 0.0
    return prop_tax * max(capex - capex / dep_years * (t - 0.5), 0)

def flows_onprem(years=H, p=onprem, extend=False):
    rows = []
    for t in range(years + 1):
        row = {"Год": t, "Оборудование и ПО": p["capex"] if t == 0 else 0, "Настройка": p["setup"] if t == 0 else 0,
               "Эксплуатация": p["energy"] if t else 0, "Персонал": p["staff"] if t else 0,
               "Обновление ПО": p["sw_update"] if t else 0, "Обучение": p["training"] if t == 1 else 0,
               "Простои": p["downtime"] if t else 0,
               "Модернизация": p["modern"] if (t and t % 3 == 0 and (extend or t == 3)) else 0,
               "Налог на имущество": avg_residual_tax(p["capex"], t)}
        rows.append(row)
    return pd.DataFrame(rows).set_index("Год")

def flows_cloud(years=H, p=cloud, k_cloud=1.0):
    rows = []
    for t in range(years + 1):
        rows.append({"Год": t, "Миграция": p["setup"] if t == 0 else 0,
                     "Облачные услуги": p["cloud"] * k_cloud * (1 + p["growth"]) ** (t - 1) if t else 0,
                     "Персонал": p["staff"] if t else 0, "Поддержка": p["support"] if t else 0,
                     "Обучение": p["training"] if t == 1 else 0})
    return pd.DataFrame(rows).set_index("Год")

def flows_hybrid(years=H, p=hybrid, k_cloud=1.0, tax=True, extend=False):
    rows = []
    for t in range(years + 1):
        rows.append({"Год": t, "Оборудование": p["capex"] if t == 0 else 0, "Настройка": p["setup"] if t == 0 else 0,
                     "Облачные услуги": p["cloud"] * k_cloud if t else 0, "Эксплуатация": p["ops"] if t else 0,
                     "Персонал": p["staff"] if t else 0, "Поддержка": p["support"] if t else 0,
                     "Модернизация": p["modern"] if (t and t % 3 == 0 and (extend or t == 3)) else 0,
                     "Налог на имущество": avg_residual_tax(p["capex"], t) if tax else 0})
    return pd.DataFrame(rows).set_index("Год")

def tco(df, rate=r):
    total = df.drop(columns="ИТОГО", errors="ignore").sum(axis=1).values
    return total.sum(), npv(total, rate)

4.3. Точка безубыточности: on-premise против облака¶

За 5 лет накопленные затраты своего ЦОДа выше облака в каждом году. Продлим срок до 15 лет при таких допущениях: оборудование не меняем (только модернизация раз в 3 года), после 5-го года налог на имущество не платим (оборудование самортизировано), облако дальше дорожает на 5 % в год.

6. Интерпретация результатов¶

  • Самая низкая TCO у облака, на втором месте гибрид, самый дорогой свой ЦОД. Приведённая TCO: облако 93 млн руб., гибрид 116 млн, on-premise 176 млн. Облако дешевле своего ЦОДа примерно на 47 %. Главная причина: огромные вложения в свой ЦОД в году 0 (около 97 млн руб.), а ежегодные затраты у вариантов похожи (19–26 млн руб. в год).
  • Точки безубыточности за 5 лет нет. Если продлить срок, свой ЦОД начинает догонять только после полной амортизации, потому что ежегодно он дешевле. Без дисконтирования он догоняет облако только на 14-м году, а с дисконтированием (12 %) не догоняет и за 15 лет. И это если серверы не придётся менять, что нереально: обычно они служат 5–7 лет.
  • Ставка дисконтирования выбор не меняет: облако лучше при 8, 12 и 16 %. Чем выше ставка, тем сильнее она бьёт по крупным начальным вложениям, и преимущество облака только растёт.
  • Цена облака ±20 % тоже ничего не меняет: облако всё равно намного дешевле своего ЦОДа. С гибридом облако сравняется, только если облачные цены вырастут примерно на 66 %.

7. Выводы и рекомендации¶

Рекомендуем облако (IaaS + PaaS): самая низкая TCO, мало денег на старте (около 5 млн руб. против 97 млн), легко масштабироваться, затраты становятся текущими, нет риска, что оборудование устареет.
