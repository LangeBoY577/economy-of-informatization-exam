1. Экономическая постановка задачи¶

Госучреждение думает о внедрении электронного документооборота. Нужно вложить 55 млн руб. и тратить 9 млн руб. в год. Взамен экономится время сотрудников и бумага, меньше ошибок, процессы идут быстрее. Вопрос: окупятся ли вложения и при каких условиях проект станет выгодным.

Цель: посчитать NPV, IRR, сроки окупаемости и ROI, проверить чувствительность и найти порог безубыточности.

Тема лекции №8: ROI, TEI, NPV, IRR, простой и дисконтированный срок окупаемости, амортизация и налог в денежном потоке, неденежные выгоды в госсекторе.

Допущения:

  • Неденежную выгоду (удовлетворённость граждан, 1 млн руб.) в основной расчёт не включаем: живых денег она не приносит. Её влияние показано отдельным сценарием (подход TEI).
  • Амортизируем только оборудование (15 млн руб. / 5 лет = 3 млн руб. в год), как сказано в условии. Разработка и обучение идут вложениями года 0 без налоговой экономии на амортизации (осторожная оценка). Вариант, где разработка учитывается как НМА, есть в чувствительности.
  • Налог на прибыль 20 % берём с прироста прибыли (выгоды − затраты − амортизация).

3. Математическая модель¶

$$CF_t = (B_t - C_t - D_t)(1-T) + D_t,\qquad t=1..5;\qquad CF_0=-I$$ $$NPV=\sum_{t=0}^{5}\frac{CF_t}{(1+r)^t},\qquad NPV(IRR)=0,\qquad ROI=\frac{\sum_{t=1}^5 CF_t - I}{I}$$ $$PP:\ \sum_{k\le PP} CF_k=0,\qquad DPP:\ \sum_{k\le DPP}\frac{CF_k}{(1+r)^k}=0$$ Порог безубыточности по экономии времени $S^*$ находим из условия $NPV(S^*)=0$.

def cash_flows(time_saving=benefits["Экономия времени сотрудников"], dev_cost=dev, rate_tax=tax,
               extra_benefit=0.0, amortize_dev=False):
    """Денежный поток проекта по годам (млн руб.)."""
    invest = dev_cost + equipment + training
    B = time_saving + sum(v for k, v in benefits.items() if k != "Экономия времени сотрудников") + extra_benefit
    C = licenses + support + admin
    D = equipment / dep_years + (dev_cost / dep_years if amortize_dev else 0)
    rows = [{"Год": 0, "Инвестиции": invest, "Выгоды": 0, "Затраты": 0, "Амортизация": 0, "Прибыль до налога": 0,
             "Налог": 0, "Чистая прибыль": 0, "CF": -invest}]
    for t in range(1, H + 1):
        ebt = B - C - D
        tx = max(ebt, 0) * rate_tax
        rows.append({"Год": t, "Инвестиции": 0, "Выгоды": B, "Затраты": C, "Амортизация": D, "Прибыль до налога": ebt,
                     "Налог": tx, "Чистая прибыль": ebt - tx, "CF": ebt - tx + D})
    return pd.DataFrame(rows).set_index("Год")

6. Интерпретация результатов¶

  • Вложения 55 млн руб., ежегодные затраты 9 млн руб., денежные выгоды 15 млн руб. в год. До амортизации остаётся всего 6 млн руб. в год, чистый денежный поток 5,4 млн руб. в год.
  • NPV около −34,5 млн руб.: за 5 лет проект возвращает только 27 млн руб. из 55. IRR отрицательная (около −20 %), то есть не возвращаются даже вложенные деньги без учёта процентов. ROI около −51 %, проект не окупается за срок расчёта.
  • Чувствительность. NPV не становится положительным ни при какой ставке от 8 до 14 %, ни при ±20 % экономии времени или стоимости разработки, ни с неденежной выгодой, ни без налога. Проблема в самой конструкции: годовой выигрыш слишком мал по сравнению с вложениями. Сильнее всего влияет стоимость разработки.
  • Порог безубыточности: экономия времени должна быть около 19,4 млн руб. в год вместо 8 (в 2,4 раза больше), либо вложения не больше 20,5 млн руб. (на 63 % меньше).

7. Выводы и рекомендации¶

Вывод: при нынешних цифрах проект невыгоден (NPV < 0, IRR < 0, за 5 лет не окупается). Для госучреждения его можно оправдать только как социально значимый, но тогда обосновывать нужно не через NPV, а через качество услуг и скорость обработки обращений.

Рекомендации

  1. Уменьшить масштаб. Взять готовую тиражируемую СЭД вместо заказной разработки. Если вложения снизятся примерно до 20 млн руб., проект выйдет в ноль.
  2. Внедрять по этапам. Начать с подразделений, где документов больше всего и экономия времени максимальна.
  3. Закупать вместе с другими учреждениями (единая платформа), чтобы разделить затраты на разработку.
  4. Точнее посчитать выгоды. Замерить реальную экономию времени, ускорение процессов, меньшие штрафы за просрочки. Возможно, выгоды недооценены.
  5. Взять срок больше. СЭД обычно живёт 7–10 лет. На 10 годах NPV лучше, но без снижения затрат всё равно отрицательный.
