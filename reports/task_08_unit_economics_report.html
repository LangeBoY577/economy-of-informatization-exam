1. Экономическая постановка задачи¶

Стартап «Еда-Быстро» запускает доставку готовой еды. Прежде чем тратить деньги на рекламу, нужно понять, зарабатывает ли бизнес на одной единице: одном заказе и одном клиенте. Юнит-экономика отвечает на три вопроса: приносит ли заказ прибыль, окупается ли привлечение клиента (LTV/CAC, payback) и сколько нужно клиентов, чтобы покрыть постоянные расходы.

Цель: посчитать юнит-экономику, оценить, жизнеспособна ли модель, и предложить, как её улучшить.

Важно про условие. В условии есть и «комиссия сервиса 20 % от чека», и полная себестоимость заказа (продукты, упаковка, доставка). Отсюда две возможные модели:

  • Модель А (агрегатор): сервис получает только комиссию 20 % (120 руб.), но платит за всё выполнение заказа;
  • Модель Б (своя кухня): сервис сам готовит и продаёт еду, его доход весь чек 600 руб.

Модель А это буквальное прочтение условия (под неё написаны формулы ARPU и LTV в задании). Модель Б логичнее: кто платит за продукты, тот и получает за них деньги. Считаем обе и сравниваем.

Тема лекции №9: юнит-экономика, маржинальный доход, ARPU, LTV, CAC, LTV/CAC, payback, отток, точка безубыточности.

3. Математическая модель¶

$$CM_{заказ} = Доход_{заказ} - \sum VC_{заказ},\qquad ARPU = Доход_{заказ}\cdot n_{заказов},\qquad CM_{клиент} = CM_{заказ}\cdot n_{заказов}$$ $$LTV_{выр} = \frac{ARPU}{churn}\ (\text{формула курса}),\qquad LTV_{маржа} = \frac{CM_{клиент}}{churn},\qquad Payback=\frac{CAC}{CM_{клиент}}$$ $$\Pi_{опер} = N\cdot CM_{клиент} - FC,\qquad N_{безуб} = \frac{FC}{CM_{клиент}}\ \ (CM_{клиент}>0)$$ Срок жизни 12 мес. почти совпадает с оттоком: $1/0{,}08 = 12{,}5$ мес. Сравнивать с CAC правильнее LTV по марже: LTV по выручке завышает ценность клиента, потому что не учитывает затраты на выполнение заказов.

def unit(revenue_per_order, n=orders_m, ch=churn, cac=CAC, vc=VC, fc=FC, N=clients):
    cm_order = revenue_per_order - vc
    arpu = revenue_per_order * n
    cm_client = cm_order * n
    res = {"Доход с заказа, руб.": revenue_per_order, "Переменные затраты, руб.": vc, "Маржа заказа CM, руб.": cm_order,
           "ARPU, руб./мес.": arpu, "Маржа клиента, руб./мес.": cm_client,
           "LTV по выручке (ARPU/churn), руб.": arpu / ch, "LTV по марже, руб.": cm_client / ch,
           "LTV(выр)/CAC": arpu / ch / cac, "LTV(маржа)/CAC": cm_client / ch / cac,
           "Payback, мес.": cac / cm_client if cm_client > 0 else np.inf,
           "Доход сервиса в месяц, руб.": arpu * N, "Маржа всех клиентов, руб./мес.": cm_client * N,
           "Постоянные затраты, руб./мес.": fc, "Операционная прибыль, руб./мес.": cm_client * N - fc,
           "Клиентов для безубыточности": fc / cm_client if cm_client > 0 else np.inf}
    return pd.Series(res)

6. Интерпретация результатов¶

Модель А (буквальная). Сервис получает 120 руб. с заказа, а тратит 468 руб. Итог: −348 руб. на каждом заказе, −870 руб. на клиента в месяц. ARPU 300 руб., LTV по формуле курса 3 750 руб., LTV/CAC 1,5, это ниже нормы 3. А по марже LTV вообще отрицательный. Привлечение не окупается никогда, операционный убыток около −2,47 млн руб. в месяц при 1 000 клиентах (870 тыс. убытка на заказах + 1,6 млн постоянных расходов). Безубыточности нет при любом числе клиентов: каждый новый клиент только увеличивает убыток. Даже после всех улучшений заказ остаётся убыточным. По сути сервис доплачивает за еду ресторанов, так работать нельзя.

Модель Б (своя кухня). Маржа заказа +132 руб. (22 % чека), на клиента 330 руб. в месяц, LTV по марже около 4 125 руб., LTV/CAC около 1,65, клиент окупается примерно за 7,6 месяца. При сроке жизни 12 месяцев он окупается, но запаса мало. При 1 000 клиентов убыток около −1,27 млн руб. в месяц, безубыточность начинается примерно с 4 850 активных клиентов. После улучшений (чек 700 руб., дешевле доставка, отток 6 %) LTV/CAC больше 3, окупаемость меньше 5 месяцев, а для безубыточности хватает примерно 2 500 клиентов.

Главный вывод: в обеих трактовках модель сейчас нежизнеспособна, LTV/CAC меньше 3. Основные рычаги: маржа заказа (чек, себестоимость, доставка) и удержание клиентов. LTV обратно пропорционален оттоку.

7. Выводы и рекомендации¶

  1. Определиться с моделью бизнеса. Если сервис агрегатор (модель А), он не должен платить за еду, это делает ресторан. Если у сервиса своя кухня (модель Б), его выручка весь чек. Смесь «комиссия 20 % + полная себестоимость» убыточна в принципе.
  2. Целевые метрики: LTV(по марже)/CAC не меньше 3, окупаемость клиента не дольше 6 месяцев, маржа заказа от 25 % чека.
Направление Что делать Эффект
Средний чек комбо-наборы, допродажа напитков и десертов, минимальная сумма заказа +100 руб. к чеку
Себестоимость общие закупки, единое меню для кухни −30…−50 руб. на заказ
Доставка объединять заказы, зоны доставки, платная доставка для маленьких заказов −20…−40 руб. на заказ
Частота подписка на обеды для офисов (B2B), программа лояльности +0,5 заказа в месяц
Удержание контроль качества и времени доставки, личные предложения отток 8 % → 5–6 %
CAC реферальная программа, партнёрства с бизнес-центрами 2 500 → 1 500–2 000 руб.
Постоянные расходы не увеличивать маркетинг, пока LTV/CAC меньше 3 экономия денег
  1. Порядок действий: сначала добиться нормальной маржи заказа на текущих клиентах, потом снижать отток, и только когда LTV/CAC дойдёт до 3, увеличивать бюджет на привлечение.
