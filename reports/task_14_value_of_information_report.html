1. Экономическая постановка задачи¶

Перед запуском проекта можно заказать исследование (рынка или технологии) за 5 млн руб. Оно повышает шанс успеха с 50 % до 80 %. Нужно решить, стоит ли за это платить. Это классическая задача о ценности информации: информация стоит ровно столько, насколько она улучшает ожидаемый результат.

Цель: посчитать ожидаемую прибыль без исследования и с ним, ценность информации и принять решение с учётом рисков.

Тема лекции №15: решения в условиях неопределённости, ожидаемая стоимость, ценность информации (EVSI, EVPI), дерево решений, отношение к риску.

Принимаем 0 (проект просто ничего не приносит), а вариант с убытком проверяем в анализе рисков.

3. Математическая модель¶

$$E[\Pi_{без}] = p_0\cdot\Pi\cdot DF + (1-p_0)\cdot L\cdot DF,\qquad E[\Pi_{с}] = p_1\cdot\Pi\cdot DF + (1-p_1)\cdot L\cdot DF - C_{иссл}$$ $$\text{Ценность информации (EVSI)} = (p_1-p_0)(\Pi - L)\cdot DF,\qquad \text{исследовать, если } EVSI > C_{иссл}$$ где $DF = 1/(1+r)^3 = 0{,}7513$ для варианта А или $DF = \tfrac{1}{3}\sum_{t=1}^3 (1+r)^{-t} = 0{,}829$ для варианта Б.

Минимальный шанс успеха после исследования, при котором оно окупается: $p_1^* = p_0 + \dfrac{C_{иссл}}{(\Pi-L)\cdot DF}$.

Для сравнения ценность совершенной информации (EVPI): если бы заранее точно знали, получится ли проект, неудачный можно было бы не запускать: $EVPI = (1-p_0)\cdot\max(0, -L)\cdot DF$.

DF_A = 1 / (1 + r) ** H
DF_B = annuity_factor(r, H) / H
def evaluate(DF, p0=p_no, p1=p_yes, P=profit, L=loss_fail, C=research_cost):
    e_no = (p0 * P + (1 - p0) * L) * DF
    e_yes = (p1 * P + (1 - p1) * L) * DF - C
    evsi = (p1 - p0) * (P - L) * DF
    return {"E[прибыль] без исследования": e_no, "E[прибыль] с исследованием (за вычетом 5 млн)": e_yes,
            "Ценность информации EVSI": evsi, "Чистая ценность (EVSI − стоимость)": evsi - C,
            "Пороговая p₁*": p0 + C / ((P - L) * DF), "Решение": "исследовать" if evsi > C else "не исследовать"}

# Распределение результата (вариант А): дисперсия и вероятность убытка
def risk(p, C, L=loss_fail, DF=DF_A):
    outcomes = np.array([profit * DF - C, L * DF - C]); probs = np.array([p, 1 - p])
    mean = outcomes @ probs; sd = np.sqrt(((outcomes - mean) ** 2) @ probs)
    return {"Ожидание, млн": mean, "Ст. отклонение, млн": sd, "Коэфф. вариации": sd / mean,
            "P(результат ≤ 0)": probs[outcomes <= 0].sum(), "Худший исход, млн": outcomes.min()}
rk = pd.DataFrame({"Без исследования": risk(p_no, 0), "С исследованием": risk(p_yes, research_cost)})

6. Интерпретация результатов¶

  • Без дисконтирования: без исследования ожидаемая прибыль 15 млн руб., с исследованием 24 млн руб. Ценность информации 9 млн руб. больше цены 5 млн руб., исследование выгодно, чистый выигрыш 4 млн руб.
  • С дисконтированием (10 %, 3 года): ценность информации падает примерно до 6,8 млн руб. (вариант А) или 7,5 млн руб. (вариант Б), но всё равно больше цены исследования. Чистый выигрыш 1,8–2,5 млн руб. Решение: исследовать. Важно: платим за исследование сейчас, а выгода приходит через годы. Без дисконтирования выигрыш завышается больше чем вдвое (4,0 против 1,8 млн руб.).
  • Запас небольшой: исследование окупается, только если поднимает шанс успеха хотя бы до 72 % (обещано 80 %). Если реальный эффект окажется меньше, решение меняется.
  • Риск: исследование снижает шанс нулевого результата с 50 % до 20 % и уменьшает разброс. То есть одновременно растёт ожидаемый результат и падает риск. Для осторожного инвестора это ещё один аргумент «за».
  • Особенность условия: при неудаче результат 0, убытка нет. Поэтому совершенная информация об исходе здесь ничего не стоит (EVPI = 0): знание «проект провалится» не помогает ничего сэкономить. Исследование полезно не как прогноз, а как улучшение проекта (оно повышает шанс успеха). Если бы неудача давала убыток, информация была бы ценна ещё и тем, что позволяет отказаться от проекта.
