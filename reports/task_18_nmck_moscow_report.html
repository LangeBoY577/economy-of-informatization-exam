1. Экономическая постановка задачи¶

Для госзакупки разработки ИС нужно определить начальную (максимальную) цену контракта (НМЦК). В Москве для этого есть методика (распоряжение № 64-16-89/18/3-р): размер ИС в функциональных точках, затем трудозатраты по модели COCOMO с московскими коэффициентами, затем численность и квалификация команды, затем стоимость работ. Правильная НМЦК защищает и от переплаты, и от того, что на заниженную цену никто не придёт.

Цель: посчитать размер ИС, трудозатраты, численность исполнителей и НМЦК.

Тема лекции №19: методика г. Москвы, функциональные точки, коэффициенты трудоёмкости МТ1–МТ7, коэффициенты численности и квалификации, средняя выработка.

Допущения:

  • «МТi = 0,85» можно понять двумя способами: (а) произведение всех семи коэффициентов $\prod МТ_i = 0{,}85$ (так в примере методики: «МТ1–МТ7 = 0,740 (произведение)»); (б) каждый из семи равен 0,85, тогда произведение $0{,}85^7 \approx 0{,}32$. Вариант (б) нереален: значение 0,85 в таблицах есть только у МТ4 (информационно-поисковая ИС), у МТ3, МТ5, МТ7 минимум 0,95–1,00. Берём (а), вариант (б) показываем для сравнения.
  • Индекс зарплаты старшего аналитика в лекции не дан, берём 1,15 (между архитектором 1,40 и аналитиком 0,90).
  • Все роли заняты полностью весь проект: $К_{уч} = 1$.
  • $К_{пер} = 1{,}064$ из лекции. Насколько он актуален, проверено в анализе чувствительности.

3. Математическая модель¶

$$РР = \frac{ФТ\cdot К_п}{1000}\ [\text{тыс. строк}],\qquad ОТр = A\cdot РР^{B}\cdot\prod МТ_i\ [\text{чел.-мес.}]$$ $$Ч_i = \frac{ОТр}{Т_п}\cdot Кч_i,\qquad Ч_п = \sum_i Ч_i + Ч_{РП},\qquad К_{кв} = \frac{\sum_i Ч_i\cdot К_{уч,i}\cdot И_i}{Ч_п}$$ $$В_{ср} = \frac{ЗПБ_{2015}\cdot К_{пер}\cdot(1+Р)}{К_3},\qquad НМЦК = В_{ср}\cdot Т_п\cdot Ч_п\cdot К_{кв}\ (\text{без НДС})$$

def nmck(fp=FP, k_lang=K_lang, mt=MT_prod, tp=Tp, p=P, k_per=K_per, pm=True):
    rr = fp * k_lang / 1000; otr = A * rr ** B * mt
    ch = otr / tp * roles["Кч"]; chp = ch.sum() + (1 if pm else 0)
    kkv = ((ch * roles["Индекс И"]).sum() + (pm_index if pm else 0)) / chp
    return otr, chp, ZPB * k_per * (1 + p) / K3 * tp * chp * kkv / 1e6

6. Интерпретация результатов¶

  • Размер ИС: 450 ФТ × 53 = 23,85 тыс. строк условного кода (Java).
  • Трудозатраты: около 86,6 чел.-мес. ОТр/Тп около 14,4, это в диапазоне 10–30, значит, табличные коэффициенты численности применимы.
  • Численность: около 16,9 человека (19 при округлении по ролям, с руководителем проекта). Больше всего аналитиков-разработчиков (около 7,5) и архитекторов (около 3,3), тестировщиков около 2,5. Средний коэффициент квалификации около 1,14: команда сильнее «базовой», потому что сжатый срок 6 месяцев требует архитекторов и руководителя.
  • НМЦК около 16,2 млн руб. без НДС (19,5 млн руб. с НДС) при выработке около 141 тыс. руб. на человеко-месяц.
  • Чувствительность. Сильнее всего влияют трактовка МТ (вариант «каждый МТ = 0,85» снижает цену на 56 %, это грубая ошибка), коэффициент пересчёта зарплаты и размер ИС (±20 % размера дают примерно ±17 % цены). Срок влияет слабо: при 9 месяцах людей нужно меньше, а цена даже растёт на 5 %, потому что руководителю проекта платят дольше.
  • Важно: $К_{пер}=1{,}064$ это индексация к базе 2015 года, она явно не учитывает рост зарплат в ИТ к 2026 году. При реальной индексации (К_пер около 1,9) НМЦК была бы больше примерно на 79 %. С заниженной ценой на торги могут никто не прийти или придут недобросовестные участники с демпингом.
